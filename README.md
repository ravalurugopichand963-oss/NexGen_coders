# 🛡️ Girls Safe Travel

A Smart India Hackathon prototype for improving women's safety during public transportation.

## Features

- 📷 Driver QR code scanning using phone camera
- 🚗 Driver verification/details
- 👤 Passenger registration
- 📍 Source and destination
- 📏 Route distance
- ⏱️ Estimated journey time
- 📡 Live GPS location
- 🗺️ Google Maps live-location link
- 🚨 Wrong-route detection
- 📞 Emergency call to 112
- 📞 Passenger emergency contact call
- 📱 SOS SMS
- ✅ Safe-arrival confirmation
